# App Icons

This directory should contain:
- icon-192.png (192x192 pixels)
- icon-512.png (512x512 pixels)

You can create these icons using:
1. Any image editor (Photoshop, GIMP, etc.)
2. Online tools like https://realfavicongenerator.net/
3. Design tools like Figma, Canva, etc.

The icons should represent your app and work well on both light and dark backgrounds.
